### 🛠️ What I'm building

| Project | What it is |
|---------|------------|

### 🧱 How I work

**Build → codify → cite → diagnose → measure.**

Every workflow I run twice becomes a reusable skill. Every claim ships with a source. When an AI system stalls, I treat it as a research problem — not a prompt to tweak.
